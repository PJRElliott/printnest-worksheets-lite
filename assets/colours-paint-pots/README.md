# Colours Paint-Pot Assets

Eleven colour-vocabulary illustrations for early-years and KS1 Trace and Write worksheets.

## Teaching Set

1. red
2. orange
3. yellow
4. green
5. blue
6. purple
7. pink
8. brown
9. black
10. white
11. grey

The England curriculum does not prescribe a fixed list of colour names. This practical set combines the common primary, secondary, neutral, and early-vocabulary colours. It supports the Development Matters expectations to discuss differences between colours and explore colour mixing, and the KS1 Art and Design requirement to develop techniques using colour.
